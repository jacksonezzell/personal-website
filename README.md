# Personal Website & Portfolio

This repository contains the source code for my personal website and professional portfolio.
The site highlights my background in atmospheric and environmental sciences, research projects,
and technical work.

## Overview
The website is built as a lightweight Flask application using HTML, CSS, and Jinja2 templates.
It serves as a centralized place to share my resume, research posters, and ongoing technical
projects.

## Tech Stack
- Python (Flask)
- HTML / CSS
- Jinja2 Templates
- Nginx (production deployment)
- Git & GitHub for version control
